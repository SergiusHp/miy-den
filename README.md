# Мій день — веб-застосунок

Як відкрити: двічі клацни `index.html` — застосунок відкриється в браузері.
На ПК він показується в рамці телефону, на телефоні — на весь екран.

## Структура

```
index.html      — розмітка всіх 6 екранів (кожен екран — <section class="scr">)
css/style.css   — стилі; кольори й шрифти — змінні на початку файлу (:root)
js/app.js       — логіка: навігація, планувальник, таймер «Фокус»
assets/         — фони та іконки (вирізані з «Кнопки та іконки.png»)
```

## Екрани

1. `splash` — заставка
2. `onb1`, `onb2`, `onb3` — знайомство (онбординг)
3. `day` — «Мій день»: «План без часу» (швидке додавання), «Розклад» з часом і «Виконано» внизу; вигляди тиждень і місяць.
   Галочка — конфеті й переїзд справи у «Виконано»; свайп ліворуч — видалення (з кнопкою «Повернути»).
4. `focus` — таймер «Фокус»: режими «Перерва», «Коротка», «Довга», «Власний».
   У «Перерві» й «Власному» час налаштовується колом, яке крутиться пальцем (6° = 1 хв, оберт = 60 хв, до 3 год).
   Іконки режимів — з Figma, бібліотека «Simple Design System» (Pause circle, Coffee, Book open, Sliders), вбудовані як SVG в `index.html`.
5. `goals` — «Цілі»: вкладки «День», «Місяць», «Рік», з прогресом виконання
   - темп: прогрес порівнюється з часом, що минув (риска на смужці, статус «За планом / Відстаєш»);
   - головна ціль ★ періоду, мотивація «Навіщо мені це», звʼязок «Крок до цілі» (день → місяць → рік);
   - «+ У план» — додає крок до цілі в план на сьогодні;
   - перенесення незавершених цілей з попереднього періоду, фільтр за сферами, поради тренера.

Будь-який екран можна відкрити одразу: `index.html#day`, `index.html#focus`.

## Що де правити

- **Кольори** — `css/style.css`, блок `:root` (наприклад `--teal`, `--gold-2`).
- **Тексти екранів** — `index.html`.
- **Приклад справ на день** — `js/app.js`, масив `SAMPLE_DAY` (справа без часу — це `start: ''`).
- **Вірші дня** — `js/app.js`, масив `VERSES`.
- **Тривалість режимів таймера** — `js/app.js`, об'єкт `MODES`; межі кола-регулятора — `DIAL_MIN` / `DIAL_MAX`.
- **Поріг свайпу для видалення** — `js/app.js`, `SWIPE_DELETE_SHARE` (частка ширини картки).
- **Скляна кнопка «+»** — `css/style.css`, блок `.fab` (прозорість, розмиття, стан натискання `.pressed`).
- **Приклади цілей** — `js/app.js`, функція `sampleGoals`.
- **Пороги статусів темпу** — `js/app.js`, функція `paceByGap`.
- **Тексти порад тренера** — `js/app.js`, функція `renderTip`.
- **Сфери життя за замовчуванням і палітра кольорів** — `js/app.js`, `DEFAULT_SPHERES` і `SPHERE_PALETTE`.
  Свої сфери можна змінити прямо в застосунку: «Цілі» → «✎ Сфери життя».
- **Пункти нижнього меню** — `index.html`, блок `<nav class="tabbar">`.

Справи, цілі, сфери життя та статистика фокусу зберігаються в браузері (localStorage).
Щоб почати «з нуля», очисти дані сайту в браузері.
